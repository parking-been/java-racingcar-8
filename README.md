# 🚗 자동차 경주

---

### 기능 요구사항

초간단 자동차 경주 게임을 구현한다.

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

# 💻 MVC 패턴 구성 연습

---

### 이야기

경기에 참여할 n개의 자동차들의 자동차 경주 게임을 구현한다.

최대한 임무에 따라 사람을 설정함

진행자, 심판, 자동차, 자동차 관리인, 서기가 있다

- 경주 게임을 준비함
    - 자동차 관리인이 경주에 참여할 자동차들의 이름을 받음
    - 자동차 관리인이 자동차들이 게임을 준비할 것을 명령함
        - 각각의 자동차들은 준비함
    - 서기는 경주 게임 진행을 위해 경주 게임의 시간을 받음
- 아래가 반복됨
    - 진행자가 자동차들이 움직일 것을 명령함
        - 자동차 관리인이 자동차들을 이동하라고 함
            - 자동차들이 각각 조건이 맞는지 확인하고 이동함
    - 진행자가 현재 자동차들의 위치를 물어봄
        - 자동차 관리인이 자동차 위치를 알려줌
    - 진행자가 시행 횟수가 남았는지 서기한테 물어봄
        - 서기가 경기가 끝났는지 아닌지 여부를 결정함
- 게임이 끝난 후 진행자가 심판에게 경기 결과를 물어봄
    - 진행자가 심판에게서 경기 결과를 발표함
        - 진행자가 경기 결과 발표함

### 협력 : 요청과 응답

- 누군가가 진행자에게 경기를 요청함으로써 경기가 시작됨
- 자동차 관리인이 경주 게임을 준비함
    - 자동차 관리인은 게임에 참여할 자동차의 이름을 받고 게임을 준비시킴으로써 응답함
- 서기가 경주 게임을 준비함
    - 서기는 경주 게임 진행을 위해 경주 게임 시간을 받고 게임 횟수 counting 준비함으로써 응답함.
- 아래가 반복됨
    - 진행자가 자동차 관리인에게 자동차들이 움직일 것을 요청함
        - 자동차 관리인은 자동차들에게 이동하라고 요청함
            - 자동차들은 조건이 맞는지 확인하고 이동함으로써 응답함
    - 진행자가 자동차 관리인에게 현재 자동차들의 위치를 알려줄 것을 요청함
        - 자동차 관리인은 자동차들에게 현재 위치를 알려달라고 요청함
            - 자동차들은 각자의 위치를 알려줌으로써 요청에 응답함
    - 진행자가 서기에게 남은 이동 횟수를 요청함
        - 서기는 남은 이동 횟수를 전달함으로써 경기 진행 가능 여부를 응답함
- 진행자가 심판에게 경기 결과를 요청함
    - 심판은 우승자 결정을 위해 자동차 관리인에게 주행거리를 요청함
        - 자동차 관리인은 자동차들에게 주행거리를 요청함
            - 자동차들은 주행거리를 응답함
    - 자동차 주행거리를 토대로 심판이 우승자를 결정함

### 책임 : 하는 것과 아는 것

진행자

- 하는것 :
    - 자동차 관리인에게 자동차들을 움직일 것을 명령함
    - 자동차 관리인에게 현재 주행 거리를 알려줄 것을 명령함
    - 서기에게 남은 이동횟수를 요청함
    - 심판에게 경기 결과를 요청함

자동차 관리인

- 하는것 :
    - 자동차들에게 게임을 준비하라 요청함
    - 자동차들에게 움직이라 요청
    - 자동차들에게 주행 거리를 알려달라 요청
- 아는것 : 게임에 참가하는 자동차들

자동차

- 하는것 :
    - 게임을 준비함(생성): 이름을 받음
    - 이동 조건 확인한후 이동하거나 멈춘다.
- 아는것 : 주행거리, 이름, 주행 조건

서기

- 하는것 : 경기 진행 여부 판단
- 아는것 : 남은 이동 횟수, 총 경기 회수

심판

- 하는것 : 우승자 가리기

### 역할 : 책임의 집합

- 진행자 → Racing
- 자동차 관리인 → Cars
- 자동차 → Car
- 서기 → Counter
- 심판 → RacingResult

# ✒️ 구현할 기능 목록

---

### 입력 멘트 & 입력값 받기

- 입력 멘트 : 경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
    - 입력값1 받기
        - null 이거나 아무것도 입력을 하지 않은 경우 예외처리
        - (,) 기준으로 나누어 list로 만들기
- 입력 멘트 : 시도할 횟수는 몇 회 인가요?
    - 입력값2 받기
        - null 이거나 아무것도 입력을 하지 않은 경우 예외처리
        - 숫자로 이루어지지 않았으면 예외처리
        - 아니라면 숫자로 변환한다.

### 경기 준비하기

- 자동차 관리인에게 게임 준비 하라고 요청하기(자동차 관리인 생성)
    - 자동차 관리인은 자동차 이름 list를 받은 후, 자동차 생성하기
        - 자동차 이름이 5 글자 초과일경우 예외 처리
        - 자동차 이름이 중복될 경우 예외 처리
- 서기에게 게임을 준비하라고 요청하기(서기 생성)
    - 서기는 입력값2를 받는다
- 준비가 다된 자동차 관리인과 서기는 경기에 참여한다.(경기 생성)

### 경기 진행하기

- 진행자가 자동차 관리인에게 자동차들을 움직일 것을 요청함
    - 자동차 관리인은 자동차들에게 이동하라 요청함
        - 자동차들은 이동조건을 돌림
            - 랜덤한 숫자를 생성하는 class가 랜덤한 숫자를 생성하여 반환
            - 랜덤한 숫자가 조건에 맞을 경우 이동
            - 아닐경우 stay
- 진행자가 자동차 관리인에게 현재 자동차들의 위치를 알려달라 요청함
    - 자동차 관리인은 자동차들에게 현재 위치를 알려달라고 요청함
        - 자동차들은 각자의 위치를 알려줌으로써 요청에 응답함
    - 진행자가 현재 자동차 위치를 출력해줌.
- 진행자가 서기에게 경기 진행 여부를 물어봄
    - 서기는 남은 횟수를 통해 진행여부를 반환함
    - 진행자는 서기에게 반환값을 받아 경기를 진행할지 말지 판단함

### 경기 마무리하기

- 진행자가 심판에게 경기 결과를 요청함
    - 심판은 우승자 결정을 위해 자동차 관리인에게 주행거리 요청함
        - 자동차 관리인은 자동차들에게 주행 겨리 요청함
            - 자동차들은 응답함
    - 심판은 판결을 내림

### 출력 멘트  & 출력값

- 진행자는 “최종우승자 :” + 심판의 판결결과 가져와서 출력함

# 🗃️ 역할별 패키지 분리

---

**Application** : 프로그램 어플리케이션

### [domain]

**Racing**

- 자동차 관리인에게 자동차를 움직이도록 요청
- 자동차 관리인에게 자동차들의 현재 위치 요청
- 서기에게 남은 시도 횟수 요청 → 판단후 반환
- 심판에게 경기 결과 요청

**RacingResult**

- 판결 내리기

**Cars**

- 자동차들에게 이동할 것을 요청
- 자동차들의 현재 위치 요약 반환

**Car**

- 자동차 생성 기능
- 이동 시도 기능
- 현재 위치 반환

**Counter**

- 남은 시도 회수 반환

**RandomMovePolicy**

- 각 자동차들의 이동 여부 결정하는 기능

### [view]

**InputView**

- 경주할 자동차 이름 입력 받기
    - null이거나 아무것도 입력하지 않은 경우 예외처리
    - `,` 기준으로 나누어 list로 만들기
- 시도할 회수 입력 받기
    - null 이거나 아무것도 입력을 하지 않은 경우 예외처리
    - 숫자로 이루어지지 않았으면 예외처리
    - 아니라면 숫자로 변환한다.

**OutputView**

- 입력 멘트 2개 출력
- 현재 위치 출력
- 실행 결과 출력

### [controller]

**RacingController :**

- 경기 진행 (경주 상태 출력)
- 경기 마침 (우승자 출력)

### [exception]

**ErrorMessage :**

- Exception 에 대한 다양한 예외처리 메세지 문구를 저장하는 부분
